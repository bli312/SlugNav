# SlugNav - Initial Release Plan

**Team:** SlugNavDev  
**Release:** 1  
**Finalized Release Date:** 12/08/2026  
**Revision 1:** 10/12/2026  

---

## High-Level Goals

- Automatically get classes from MyUCSC
- Have an interactive map with class locations, amenities, etc.
- Be able to find routes from one point to another, with reliable time estimates
- Have users able to upload pictures and other information, with a point system/leaderboard for contributions
- Have a feature to track location to find hidden/popular routes
- Be able to handle thousands of concurrent users
- Be able to handle uploaded videos
- Be able to securely manage user data
- Have a feature to map out the insides of buildings (stretch)
- Automatically add location updates based on Canvas and Google Calendar

---

## User Stories

### Sprint 1 (Scrum Master Dan)

- **[1.1]** As a UCSC student, I want an app with an easy and intuitive UI, so that I can actually use it easily.
- **[1.2]** As a UCSC student, I want to be able to find class locations, so that I can find them easily without using the confusing UCSC interactive map.
- **[1.3]** As a UCSC student, I want my classes to load in automatically, so that I don’t have to get each one from MyUCSC.
- **[1.4]** As a UCSC student, I want the app to be secure and private, so that no one else can see my info (such as location) unless I choose to allow it.

### Sprint 2 (Scrum Master Noah)

- **[2.1]** As a UCSC student, I want to find efficient routes around campus, so that I can get to class quicker.
- **[2.2]** As a UCSC student, I want to have reliable estimates of the time to get to my classes, so I can get to class on time.
- **[2.3]** As a UCSC student, I want to be able to find amenities like water fountains and bathrooms, so that I can get to them along the way on my route, or if I need to fill up my water or use the bathroom before I leave.
- **[2.4]** As a UCSC student, I want to be able to see a preview of the classroom / what it looks like, so that I can know before ever going there or if I ever forget.
- **[2.5]** As a UCSC student, I want to be able to earn points and compete on leaderboards for my contributions, so that I can feel rewarded for contributing and receive recognition.

### Sprint 3 (Scrum Master Leo)

- **[3.1]** As a UCSC student, I want to be able to find hidden trails, so that I can have shortcuts to class and go on new/cool routes.
- **[3.2]** As a UCSC student, I want to be able to see what routes/locations are popular (and around what times), so that I can avoid crowded places or find popular places.
- **[3.3]** As a UCSC student, I want to be able to see videos of getting to classrooms, so that I can have a guide if I am unsure of how to get there.
- **[3.4]** As a UCSC student, I want to get notifications on when to leave based on my location, where I need to be, and how long it will take to get there, so I know when to go to class without having to think about it.

### Sprint 4 (Scrum Master Ian)

- **[4.1]** As a UCSC student, I want to be able to see bus info, so that I don’t have to separately check the transit app.
- **[4.2]** As a UCSC student, I want updates on my class locations/times from Canvas or Google Calendar to automatically add to my classes, so that I don’t have to manually input these.
- **[4.3]** As a UCSC student, I want an offline mode with cached map tiles and routes, since the campus has dead zones in the redwoods and in some buildings.

## Product Backlog

- As a UCSC student, I want to be able to see a route through the insides of buildings, so that I can find my classroom exactly without having to go there in person.
- As a UCSC student, I want an interactive VR map across the campus, including inside buildings, so I can really know exactly what things look like without having to walk there myself.
- As a UCSC student, I want to be able to talk to an AI agent to update things easily.
