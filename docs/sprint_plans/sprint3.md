## User Stories and Tasks

### [3.1]

As a UCSC student, I want to be able to see user data such as water fountains or bathroom locations, previews of classrooms, classroom features, etc., so that I can find them and information about them.

- [ ] Create a way for users to read/delete (manage) their uploads/creations **(3 SP) (remaining from sprint 2)**
- [ ] Create a way for users to upload media associated with classrooms or amenities **(3 SP) (remaining from sprint 2)**

### [3.2]

As a UCSC student, I want to be able to earn points and compete on leaderboards for my contributions, so that I can feel rewarded for contributing and receive recognition.

- [ ] Create the frame of leaderboard and point system **(5 SP)**
- [ ] Link User Story 2.4 with 2.5 (award points based on uploads/ratings) **(3 SP)**

### [3.3]

As a UCSC student, I want to find efficient routes with reliable estimates, so that I can get to class easily/quickly and know how long it will take me

- [ ] Be able to find routes + time estimates given location + destination using OpenRouteService **(8 SP)**
- [ ] Button for getting route and display route/estimate information on the map **(3 SP)**

### [3.4]

As a UCSC student, I want to get notifications on when to leave based on my location, where I need to be, and how long it will take to get there, so I know when to go to class without having to think about it.

- [ ] Make a way to send notifications **(3 SP)**
- [ ] Make a way to calculate if/when a notification should be given to a user based on their schedule + location + preferences **(8 SP)**

### [3.5]

As a UCSC student, I want to be able to see classroom information for a class, so I can see the location on the map and info about the classroom

- [ ] Populate initial classrooms **(5 SP)**
- [ ] Link the class info to corresponding classrooms (in places) **(7 SP)**

### [3.6]

As a UCSC student, I want to be able to access my schedule in a visual way so it is easy to view and modify it.

- [ ] Build a weekly calendar view **(3 SP)**
- [ ] Give the ability to edit the schedule from that calendar view **(2 SP)**
