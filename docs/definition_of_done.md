# Definition of Done

## Definition of Done for User Story

- All acceptance criteria met for user story
- All tasks completed (see below for definition of done for tasks)
- All tasks for the User Story moved to completed in Scrum Board
- Functionality for the user story works, work done for all the tasks are integrated

## Definition of Done for Task

- All acceptance criteria met for task
- All tests for the task are passing
- Passes GitHub check (includes TypeScript, unit tests, code coverage, linter)
- PR approved by at least one other teammate
- PR successfully merged to main
- Meets coding standards and style guide
- DB:
  - SQL migrations have been run already in Supabase
  - Has rollbacks for any SQL migrations
