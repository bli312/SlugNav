# Google sign-in button

`google-sign-in.png` is Google's unmodified light rectangular button at 3×
resolution from the [official branding assets](https://developers.google.com/static/identity/images/signin-assets.zip).
Display at 180 × 40 without changing its aspect ratio or colors.

[Branding guidelines](https://developers.google.com/identity/branding-guidelines)
