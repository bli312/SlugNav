## User Stories and Tasks

### [2.1] (formerly 1.2)

As a UCSC student, I want to see a list of classes with their building and room, so that I can check where each class meets.

- [ ] Implement a way to periodically scrape data of classes of Pisa UCSC API and store in Supabase **(8 SP) (Ian)**
- [ ] Implement a class search functionality that shows the class on the map **(5 SP) (Ian)**

### [2.2] (formerly 1.3)

As a UCSC student, I want a way to save my class information like **location**, meeting days and times, etc. so I don't have to log into MyUCSC every time to check them.

- [ ] Implement sidebar where user can navigate to in order to save class information **(2 SP) (Leo)**
- [ ] Implement functionality for users to add classes + define class table schema **(5 SP) (Noah)**
- [ ] **SPIKE (optional, if possible):** Find a way to connect MyUCSC to easily get user's class data **(Dan)**

### [2.3] (formerly 1.4)

As a UCSC student, I want my account and class data to be visible only to me, so that my information stays private unless I choose to share it.

- [ ] Define a best practices document for privacy/security, share with a team to reach an understanding, and update agent rules **(3 SP) (Leo)**

### [2.4]

As a UCSC student, I want to be able to see user data such as water fountains or bathroom locations, previews of classrooms, classroom features, etc. so that

- [ ] Create a way for users to *create* new classrooms or amenities (with locations) **(5 SP) (Leo)**
- [ ] Create a way for users to *read/delete* (manage) their uploads/creations **(5 SP) (William)**
- [ ] Create a way for users to *upload* media associated with classrooms or amenities **(5 SP) (Dan)**
- [ ] Create a way for users to view classrooms/amenities (e.g. all water fountains on map, or see water fountains near me) **(5 SP) (Dan)**
- [ ] Create a way for users to vote on predefined options about them, comment, and report **(5 SP) (Noah)**

### [2.5]

As a UCSC student, I want to be able to earn points and compete on leaderboards for my contributions, so that I can feel rewarded for contributing and receive recognition.

- [ ] Create the frame of leaderboard and point system **(5 SP) (William)**
- [ ] Link User Story 2.4 with 2.5 (award points based on uploads / ratings) **(3 SP)**
